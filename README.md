#Customer Behaviour Analysis

## 📌 Project Overview

This project analyzes customer behavior and purchasing patterns using Python, SQL, and Power BI.

The dataset contains approximately 3,900 customer records. The project follows an end-to-end data analytics workflow, starting with data cleaning and preparation in Python, followed by business-focused SQL analysis and finally an interactive Power BI dashboard with key performance indicators (KPIs).

##🛠️ Tools & Technologies

- Python — Data cleaning and preprocessing
- Pandas — Data manipulation and analysis
- SQL — Business queries and customer behavior analysis
- Power BI — Interactive dashboard and KPI visualization
- Google Colab — Python development

##🔄 Project Workflow

1. Data Cleaning & Preparation — Python

The raw dataset was cleaned and prepared using Python.

Key activities included:

- Loaded and explored the dataset
- Checked dataset structure and data types
- Identified missing values
- Checked and handled duplicate records
- Cleaned and standardized data where required
- Prepared the final dataset for SQL analysis and visualization

Dataset Size: ~3,900 rows

##3. Dashboard & KPI Analysis — Power BI

The analyzed data was then used to create an interactive Power BI dashboard.

The dashboard includes important KPIs and visualizations to monitor customer behavior and business performance.

📊 Key KPIs

The dashboard focuses on metrics such as:

- Total Customers
- Total Revenue / Sales
- Average Purchase Value
- Purchase Frequency
- Customer-related performance metrics

Additional charts and visuals were created to identify trends, comparisons, and customer purchasing patterns.

## 📈 Business Insights

The project helps answer questions such as:

- Who are the most valuable customers?
- What purchasing patterns can be observed?
- Which products or categories perform better?
- How frequently do customers purchase?
- What customer segments contribute most to business performance?
- What trends can help support business decision-making?
